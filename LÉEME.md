# PIRULETA - Overlay 3.1

Abre **Piruleta - Overlay.exe**, el acceso directo o **Abrir Piruleta.cmd**. El ejecutable incluye los recursos necesarios y no requiere Python instalado.

Mantén la app abierta mientras uses su fuente de navegador en OBS. Usa Copiar URL para OBS y configura la fuente a 1920 × 1080.

La app se organiza en Ajustes, Elementos, Diseño, Cámaras y Publicidad. La publicidad rotativa empieza con tres anuncios y permite entre dos y ocho, con botones para añadir y quitar el último.

Consulta [README.md](README.md) para instalar, conectar la API, configurar el overlay, cámaras y publicidad, guardar perfiles y generar el ejecutable desde el código. El historial está en [CHANGELOG.md](CHANGELOG.md).
